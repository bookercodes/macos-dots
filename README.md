## Principles

- Prefer a single file over multiple files, if combining them doesn’t make it unreasonably large, hard to navigate, or inefficient.

## Ghostty Shortcuts

| Shortcut | Action |
|----------|--------|
| `Shift+Enter` | Send Esc+Enter (useful for newlines in prompts) |
| `Alt+1-9` | Go to tab 1-9 |
| `Alt+T` | New tab |
| `Alt+H/J/K/L` | Navigate splits (left/down/up/right) |
| `Alt+Shift+H/J/K/L` | Resize splits |
| `Alt+D` | New split right |
| `Alt+Shift+D` | New split down |
